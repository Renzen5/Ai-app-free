
# JustWoker AI — PWA чат

Премиальный минималистичный ИИ-чат (чёрно-оранжевый) на базе JustWoker API.
Устанавливается на телефон как приложение (PWA).

## Возможности
- Чат с ИИ через JustWoker API
- История чатов хранится локально на устройстве (localStorage)
- Архив чатов (вкладка «Архив»)
- Экспорт одного чата или всех чатов в JSON (кнопка «Экспорт всех»)
- Отправка файлов (текст подставляется в сообщение) и изображений (base64)
- Просмотр изображений в полном размере
- Установка на телефон кнопкой «Установить» (PWA)
- Markdown-рендеринг ответов + кнопка «Копировать» для блоков кода

## Как задать API ключ
Два способа (можно использовать любой):

1. В приложении: Настройки → поле «API ключ». Ключ хранится только на вашем устройстве.
2. На сервере Vercel: добавьте переменную окружения `JUSTWOKER_API_KEY`.
   Settings → Environment Variables → `JUSTWOKER_API_KEY = ваш_ключ`.

> Безопасность: ключ не вшит в клиентский код. Запросы идут через серверную
> функцию `api/chat.js`, которая и обращается к JustWoker.

## Деплой на Vercel
1. Залейте папку проекта в репозиторий (GitHub/GitLab) или используйте `vercel` CLI.
2. На https://vercel.com → **New Project** → импортируйте репозиторий.
3. Framework Preset: **Other** (ничего настраивать не нужно).
4. (Опционально) добавьте переменную окружения `JUSTWOKER_API_KEY`.
5. Deploy.

После деплоя откройте сайт на телефоне — появится предложение «Установить».
На iPhone: Safari → Поделиться → «На экран Домой».

## Локальный запуск
```bash
npm i -g vercel
vercel dev
```

## Модель
По умолчанию `claude-opus-4-8` (меняется в Настройках).
